# GoLaundry
🌿 GoLaundry — Solusi Laundry Syariah untuk Gen-Z GoLaundry adalah platform laundry digital berbasis lokasi yang memudahkan mahasiswa menemukan layanan laundry terpercaya dekat kampus. Cukup klik, pilih layanan sesuai preferensi &amp; syariat, lalu pakaian dijemput dan diantar bersih tanpa ribet
